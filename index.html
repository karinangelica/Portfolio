Google Sheets, Cempaka Baru

Buka layar penuh

TokoKu Manager

  • Google Apps Script
  • Google Sheets
  • JavaScript
  • HTML & CSS

Dibuat untuk minimarket ayah saya. Lewat menu dan panel di dalam Google Sheets, toko bisa mencatat stok, menghitung harga jual GrabMart dan WhatsApp Business secara otomatis, mendapat peringatan stok tipis atau kosong, dan menyimpan kontak sales serta template balasan WhatsApp.

Di demo ini, Sidebar.html asli saya berjalan di atas tiruan Google Sheets. Coba tambah stok di tab Stok, lalu lihat selnya ikut berubah di sheet.

Harga GrabMart dihitung dengan rumus harga ÷ 0,92 × (1 + margin), lalu dibulatkan ke ratusan.

Data di demo adalah data contoh dan kembali seperti semula saat dimuat ulang. Spreadsheet asli bisa dilihat, tapi tidak bisa diubah.

Password Security Checker

  • Python
  • Keamanan siber

Alat command-line untuk mengukur kekuatan kata sandi. Entropinya dihitung dengan rumus E = L × log2(R), lalu dicek terhadap daftar kata sandi yang paling sering ditebak penyerang. Alat ini juga bisa membuat kata sandi acak yang aman secara kriptografis.

Di demo ini, file Python aslinya dijalankan langsung di browser lewat Pyodide. Coba ketik sebuah kata sandi.

Saya besar di Pontianak, kota di garis khatulistiwa, dan sejak SMA terbiasa bergerak di antara teknologi, sains, dan ekonomi.

Saat sekolah saya ikut tim competitive programming dan robotika, sekaligus menjadi sekretaris Olimpiade Ekonomi dan sekretaris Galeri Investasi & Edukasi yang bekerja sama dengan Bursa Efek Indonesia dan program Kementerian Keuangan. Di sana saya mengurus administrasi, dokumentasi, dan workshop literasi keuangan.

Banyak proyek saya lahir dari orang-orang di sekitar saya, seperti minimarket ayah saya dan anak-anak berkebutuhan khusus. Kompetisilah yang menjadi tempat saya menguji ide-ide tersebut.
